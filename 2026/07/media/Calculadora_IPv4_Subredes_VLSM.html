La idea: una IP tiene 32 bits. El prefijo indica cuántos son de red; los que quedan sirven para las direcciones de dispositivos. En una subred habitual se reservan dos direcciones: red y broadcast. Hosts utilizables = 232 − prefijo − 2.

Ejemplo: 192.168.10.13

¿Por qué se forma así la máscara?

En el último octeto, los bits encendidos tienen estos valores:

1286432168421

Ejemplo: /27 tiene 27 unos en la máscara y quedan cinco ceros. En el último octeto hay 11100000: 128 + 64 + 32 = 224. Así obtenemos 255.255.255.224.

Explicación del cálculo para cada departamento

¡Importante! Una IP libre es espacio de reserva, no un dispositivo comprado. Un portátil puede tener IP por Wi-Fi e IP por Ethernet. El gateway utiliza una dirección por VLAN; un dock USB-C no siempre necesita una IP propia. El cálculo es de direccionamiento, no configura por sí solo el firewall ni las VLAN.
