Microsoft Security #Copilot es el primer producto de seguridad que permite detectar patrones, reforzar las defensas y responder a los incidentes con mayor rapidez gracias a la IA generativa. Security Copilot combina el modelo de lenguaje generativo de OpenAI con un modelo de IA específico de seguridad desarrollado por Microsoft.

https://lnkd.in/ewG5ZaNV

Este modelo específico de seguridad incorpora un conjunto de capacidades que le permiten sintetizar datos, obtener información de vulnerabilidades, reforzar las defensas de tus activos, dar mejor respuesta a los incidentes y guardar toda esa información para colaborar con tus compañeros a través de un Pin Board o almacenar los Prompts en tu Prompt Book para reutilizarlos. Todo esto alimentado por la inteligencia global de seguridad de Microsoft, con más de 65 billones de señales diarias.
