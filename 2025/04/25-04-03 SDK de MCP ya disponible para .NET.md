Microsoft y Anthropic han unido fuerzas para desarrollar un SDK oficial en C# para el Model Context Protocol (MCP), un protocolo abierto que facilita la integración de aplicaciones de modelos de lenguaje con herramientas y fuentes de datos externas. 

Este SDK, disponible como proyecto de código abierto en GitHub, tiene como objetivo simplificar la incorporación de modelos de IA en aplicaciones C#.
