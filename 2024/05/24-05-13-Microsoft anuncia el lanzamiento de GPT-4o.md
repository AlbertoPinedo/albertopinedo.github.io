*24-05-13*

Microsoft anuncia el lanzamiento de GPT-4o, el nuevo modelo insignia de OpenAI en Azure AI. Este innovador modelo multimodal integra capacidades de texto, visión y audio, estableciendo un nuevo estándar para las experiencias de IA generativa y conversacional. GPT-4o ya está disponible en Azure OpenAI Service, para probar en vista previa, con soporte para texto e imagen.
