*24-11-06*

Ayer participé en el #CopilotTour de Microsoft en #Barcelona donde estuve explicando la importancia que tiene la seguridad de los datos. Desde Microsoft podemos ayudar en: 
1️⃣ 𝗗𝗲𝘀𝗰𝘂𝗯𝗿𝗶𝗿 𝗹𝗼𝘀 𝗿𝗶𝗲𝘀𝗴𝗼𝘀 𝗮𝘀𝗼𝗰𝗶𝗮𝗱𝗼𝘀 𝗮 𝗹𝗮 𝗜𝗔 𝘆 𝗿𝗲𝗹𝗮𝗰𝗶𝗼𝗻𝗮𝗱𝗼𝘀 𝗰𝗼𝗻: 
 - 𝗱𝗮𝘁𝗼𝘀: utilizando Microsoft Purview ofrece más de 300 clasificadores precargados para identificar diferentes SITs (Sensible Information Types)
 - 𝗮𝗰𝗰𝗲𝘀𝗼: utilizando Microsoft Purview Insider Riesk Management + Entra y Defender para entender el contexto de riesgo de los usuarios cuando usan aplicaciones de IA generativa 
 - 𝗮𝗽𝗹𝗶𝗰𝗮𝗰𝗶𝗼𝗻𝗲𝘀: Microsoft Defender for Cloud Apps ofrece un catálogo de más de 400 aplicaciones de IA generativa cada una con una evaluación de riesgos lista para ser utilizada
2️⃣ 𝗣𝗿𝗼𝘁𝗲𝗴𝗲𝗿 𝗹𝗮𝘀 𝗮𝗽𝗹𝗶𝗰𝗮𝗰𝗶𝗼𝗻𝗲𝘀 𝗱𝗲 𝗜𝗔 𝘆 𝗹𝗼𝘀 𝗱𝗮𝘁𝗼𝘀 𝘀𝗲𝗻𝘀𝗶𝗯𝗹𝗲𝘀 𝘁𝗮𝗻𝘁𝗼 𝗱𝗲 𝗣𝗿𝗼𝗺𝗽𝘁𝘀 𝗰𝗼𝗺𝗼 𝗥𝗲𝘀𝗽𝘂𝗲𝘀𝘁𝗮𝘀:
 - 𝗣𝗿𝗲𝘃𝗶𝗻𝗶𝗲𝗻𝗱𝗼 𝗹𝗮 𝗳𝘂𝗴𝗮 𝗱𝗲 𝗱𝗮𝘁𝗼𝘀 𝘆 𝗲𝗹 "𝗼𝘃𝗲𝗿𝘀𝗵𝗮𝗿𝗶𝗻𝗴": usando Microsoft Purview DLP para definir políticas de etiquetado (y auto-etiquetado) que se mapean con controles de seguridad.
 - 𝗚𝗲𝘀𝘁𝗶𝗼𝗻𝗮𝗻𝗱𝗼 𝗲𝗹 𝗮𝗰𝗰𝗲𝘀𝗼 𝗮 𝗮𝗽𝗹𝗶𝗰𝗮𝗰𝗶𝗼𝗻𝗲𝘀: Microsoft Entra y Defender proporcionan capacidades para aprobar, restringir o bloquear el acceso a aplicaciones de IA. Además con Microsoft Defender for Endpoint podemos anular la autorización y bloquear el acceso a aplicaciones de alto riesgo identificadas previamente con Microsoft Defender for Cloud Apps.
 - 𝗗𝗲𝘁𝗲𝗰𝗰𝗶ó𝗻 𝘆 𝗿𝗲𝘀𝗽𝘂𝗲𝘀𝘁𝗮 𝗮 𝗮𝗺𝗲𝗻𝗮𝘇𝗮𝘀: además de prevenir los equipos de seguridad pueden detectar y responder a amenazas potenciales, por ejemplo  interacciones sospechosas desde IPs que entrañen riesgos gracias a Microsoft Defender for Cloud Apps.
3️⃣ 𝗚𝗼𝗯𝗲𝗿𝗻𝗮𝗿 𝗲𝗹 𝘂𝘀𝗼 𝗱𝗲 𝗖𝗼𝗽𝗶𝗹𝗼𝘁 𝗽𝗮𝗿𝗮 𝗰𝘂𝗺𝗽𝗹𝗶𝗿 𝗹𝗮 𝗿𝗲𝗴𝘂𝗹𝗮𝗰𝗶ó𝗻 𝘆 𝗽𝗼𝗹í𝘁𝗶𝗰𝗮𝘀/𝗰ó𝗱𝗶𝗴𝗼𝘀 𝗱𝗲 𝗰𝗼𝗻𝗱𝘂𝗰𝘁𝗮:
 - 𝗚𝗲𝘀𝘁𝗶ó𝗻 𝗱𝗲𝗹 𝗰𝗶𝗰𝗹𝗼 𝗱𝗲 𝘃𝗶𝗱𝗮 𝗱𝗲 𝗹𝗼𝘀 𝗱𝗮𝘁𝗼𝘀: Microsoft Purview Data Lifecycle Management permite crear políticas de retención a contenido que puede ser procesado por Copilot para M365. Esto permite eliminar contenido obsoleto que Copilot pueda utilizar para generar información obsoleta.
 - 𝗗𝗲𝘁𝗲𝗰𝗰𝗶ó𝗻 𝗱𝗲 𝘂𝘀𝗼𝘀 𝗾𝘂𝗲 𝗶𝗻𝗳𝗿𝗶𝗻𝗷𝗮𝗻 𝗽𝗼𝗹í𝘁𝗶𝗰𝗮𝘀 𝗱𝗲 𝗰𝗼𝗻𝗳𝗼𝗿𝗺𝗶𝗱𝗮𝗱/𝗰𝘂𝗺𝗽𝗹𝗶𝗺𝗶𝗲𝗻𝘁𝗼: permitiendo mitigar los riesgos de conformidad en la generación de contenido (contenido confidencial, acoso, amenazas, conflictos de interes...) todo ello gracias a Microsoft Purview Communication Compliance.
 - 𝗜𝗻𝘃𝗲𝘀𝘁𝗶𝗴𝗮𝗿 𝗶𝗻𝗰𝗶𝗱𝗲𝗻𝘁𝗲𝘀 𝗱𝗲 𝗱𝗮𝘁𝗼𝘀: Microsoft Purview Audit y eDiscovery permiten realizar investigaciones y están dotadas de capacidades de recolección, preservación, revisión, análisis y exportación de las interacciones de Copilot para M365.
