Ayer participé en el #CopilotTour de Microsoft en #Barcelona donde estuve explicando la importancia que tiene la seguridad de los datos. Desde Microsoft podemos ayudar en: 1️⃣ Descubrir los riesgos asociados a la IA y relacionados con: - datos: utilizando Microsoft Purview ofrece más de 300 clasificadores precargados para identificar diferentes SITs (Sensible Information Types) - acceso: utilizando Microsoft Purview Insider Riesk Management + Entra y Defender para entender el contexto de riesgo de los usuarios cuando usan aplicaciones de IA generativa - aplicaciones: Microsoft Defender for Cloud Apps ofrece un catálogo de más de 400 aplicaciones de IA generativa cada una con una evaluación de riesgos lista para ser utilizada 2️⃣ Proteger las aplicaciones de IA y los datos sensibles tanto de Prompts como Respuestas: - Previniendo la fuga de datos y el "oversharing": usando Microsoft Purview DLP para definir políticas de etiquetado (y auto-etiquetado) que se mapean con controles de seguridad. - Gestionando el acceso a aplicaciones: Microsoft Entra y Defender proporcionan capacidades para aprobar, restringir o bloquear el acceso a aplicaciones de IA. Además con Microsoft Defender for Endpoint podemos anular la autorización y bloquear el acceso a aplicaciones de alto riesgo identificadas previamente con Microsoft Defender for Cloud Apps. - Detección y respuesta a amenazas: además de prevenir los equipos de seguridad pueden detectar y responder a amenazas potenciales, por ejemplo interacciones sospechosas desde IPs que entrañen riesgos gracias a Microsoft Defender for Cloud Apps. 3️⃣ Gobernar el uso de Copilot para cumplir la regulación y políticas/códigos de conducta: - Gestión del ciclo de vida de los datos: Microsoft Purview Data Lifecycle Management permite crear políticas de retención a contenido que puede ser procesado por Copilot para M365. Esto permite eliminar contenido obsoleto que Copilot pueda utilizar para generar información obsoleta. - Detección de usos que infrinjan políticas de conformidad/cumplimiento: permitiendo mitigar los riesgos de conformidad en la generación de contenido (contenido confidencial, acoso, amenazas, conflictos de interes...) todo ello gracias a Microsoft Purview Communication Compliance. - Investigar incidentes de datos: Microsoft Purview Audit y eDiscovery permiten realizar investigaciones y están dotadas de capacidades de recolección, preservación, revisión, análisis y exportación de las interacciones de Copilot para M365.
